# Aether Pantry

What's low or out at home, so it doesn't have to live in your head.

## Setup

1. Install the add-on and start it.
2. Open the **Aether Pantry** sidebar panel that appears in Home Assistant.
3. Aether Pantry is accessible from anywhere you can reach Home Assistant,
   including via Nabu Casa remote access.

## Relationship to Aether (chores)

Aether Pantry is a separate add-on from the Aether chore manager — its own
tab, container, and database. The two apps share design conventions (see
`docs/DESIGN_SYSTEM.md` in the repository) but no data or runtime code.
